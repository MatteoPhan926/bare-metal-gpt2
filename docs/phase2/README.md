# Phase-2 evidence index

Read [../../PHASE2_RESULTS.md](../../PHASE2_RESULTS.md) for interpretation and
[../../PHASE2_REPRO.md](../../PHASE2_REPRO.md) for exact commands. Raw values are
retained, including outliers and explicitly excluded diagnostics.

| Evidence | Directories / files |
|---|---|
| Original correctness before optimization | `baseline_gate_fp16`, `baseline_gate_int8` |
| Initial exact and unchanged HF graph gates | `graph_gate_*`, `hf_graph_*` |
| Final full-context speed/diagnostic graph equivalence | `verified_exact_fp16`, `verified_exact_int8` |
| Final unchanged HF gates, both policies/backends | `verified_hf_ordinary_*`, `verified_hf_graph_*` |
| Final standalone setup and statistical unit tests | `verified_setup`, `verified_stats` |
| Three independent unprofiled A/B runs | `fp16_run1..3`, `int8_run1..3` |
| Same-input, same-weight-value external comparison | `llama_warm1..3` |
| Native F16 external control | `llama_native_warm` |
| GGUF provenance and rounded-copy verification | `llama_weights`, `llama_weight_match` |
| Legacy-stream ordinary control | `legacy_fp16` |
| Re-measured memory bandwidth | `bandwidth` |
| Node-level Nsight timelines; every interval retained | `profile/{ordinary,graph}_{128,1023}` |
| Long-attention counters, raw CSV plus selected units | `ncu_attention_long_retry`, `ncu_attention_metrics` |
| All-run aggregation and acceptance checks | `aggregate.json`, generated by `tools/phase2_report.py` |

Each run has stdout, stderr, telemetry, and a receipt with command, return code,
source/executable/input identity and UTC timestamps. `summary.json` is a
regenerable statistical view; setup column meanings and timing boundaries are
documented in PHASE2_REPRO. `fixed_batch16` has 50 batch-average rows, not 800
individual timing samples. Every generation/advancing condition has 256 rows per
run; repeated windows are not 256 distinct contexts. Telemetry may have a partial
last line when its subprocess is terminated; the aggregator counts those lines
explicitly, without filtering any benchmark latency sample.

Non-headline diagnostics are kept: `baseline_decode` overlapped a compile;
`llama_run1` logged every replay; `llama_matched1..3` had unequal sustained warmup;
`llama_native` was also before the sustained-warmup correction. Their replacements
are named above, with no timing-based selection among valid runs. Initial
`ncu_attention_long` did not launch (wrong executable path), so its old-format
receipt has no return code; the retry succeeded. `final_exact_*` are an earlier
passing gate revision; the `verified_exact_*` tests extend speed-graph coverage.

Large .nsys-rep/.ncu-rep/SQLite binaries remain local and ignored. Portable
`kernels.csv`, `steps.csv`, `timeline.json` and NCU raw CSV retain the load-bearing
evidence. No profiler-instrumented time is used as a speed headline.
